INPUT · 4 MIN

Read, listen to your own voice, and notice

Read once for meaning. Then read aloud; on the second pass, notice how the speaker uses whole phrases.

Last week, our launch took longer than we expected. We learned that we needed earlier testing and clearer roles. The biggest lesson was to ask for help before a small problem became serious. Looking back, our instructions were not clear enough. Next time, we'll create a test plan before development ends. This experience showed me that a short conversation can save a lot of work. First, we will agree who checks each part. Then, we will share the results every day. I think these small changes will make the next launch easier for everyone on the team.

CHUNKS · 5 MIN

Five chunks to use today

Learn the whole phrase. Change the details to fit your work. Mở từng thẻ khi cần; sau đó nhìn đi chỗ khác và nói lại.

1/5 · Luyện hôm nay

We learned that…

Chúng tôi học được rằng…

Cách dùng & ví dụ
When to use
Share a lesson from a past experience.
Pattern
We learned that + clause
Simple example
We learned that testing takes time.
Work example · đổi chi tiết cho đúng với bạn
We learned that we need to test earlier.
2/5 · Luyện hôm nay

The biggest lesson was…

Bài học lớn nhất là…

Cách dùng & ví dụ
When to use
Name the most important lesson from an experience.
Pattern
The biggest lesson was + noun / to + verb
Simple example
The biggest lesson was to plan ahead.
Work example · đổi chi tiết cho đúng với bạn
The biggest lesson was to ask for help earlier.
3/5 · Luyện hôm nay

Looking back…

Nhìn lại…

Cách dùng & ví dụ
When to use
Reflect on a past decision or event.
Pattern
Looking back, + clause
Simple example
Looking back, we needed more time.
Work example · đổi chi tiết cho đúng với bạn
Looking back, we should have tested the page earlier.
4/5 · Luyện hôm nay

Next time, we'll…

Lần tới chúng tôi sẽ…

Cách dùng & ví dụ
When to use

Pattern

Simple example

Work example · đổi chi tiết cho đúng với bạn
Next time, we'll create a test plan before coding.
5/5 · Luyện hôm nay
