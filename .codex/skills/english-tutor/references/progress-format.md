# Progress file

Store tutor observations at `.english-tutor/progress.md` in the current workspace. Create the directory and file when the learner has begun meaningful practice. Keep the file concise and useful to the next tutoring session. This file supplements the browser application's local state; it does not replace it.

Use this structure:

```markdown
# English Tutor Progress

- Current day: 1
- Status: in progress
- Estimated level: A2
- Last session: YYYY-MM-DD
- Resume from: comprehension question 2
- Browser progress last observed: unknown

## Learner context

- Role/domain: unknown
- Goals: practical work English
- Preferences: 30-minute interactive lessons

## Recent evidence

- What the learner successfully understood or produced

## Recurring focus errors

- Error pattern → correction, with a short learner example

## Active chunks

- chunk — new / practicing / reliable

## Completed work

- Day N: core tasks completed; short result

## Next session

- Retrieval items and the next unfinished or planned activity
```

Update rather than append duplicate sections. Retain the most useful recent evidence and recurring patterns; remove stale detail once it no longer affects teaching. Never store sensitive personal information unless the learner explicitly wants it used for tutoring.

Do not manually claim a site lesson is completed based only on chat activity. Browser completion is recorded by the lesson page after its required checkpoints pass. When useful, ask the learner to use the site's progress export so browser state can be inspected or transferred safely.
